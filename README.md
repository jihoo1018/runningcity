## 러닝시티 핵심 시스템 구조 상세 정의 (해킹 & 보상 중심)

### I. 서비스 목표 및 핵심 콘셉트

| 항목 | 설명 |
| --- | --- |
| **핵심 목표** | **달리기 활동을 시즌제 목표 기반의 협동 RPG 미션으로 전환**하여, 사용자의 꾸준한 운동 습관 및 소셜 활동을 유도합니다. |
| **세계관** | 사용자의 러닝 에너지는 가상 도시 **'AI PULSE'**를 방어하고 악성 스팟을 정화하는 **'해킹'** 동력으로 작용합니다. |
| **핵심 재미** | **해킹을 통한 희귀 재화(데이터 칩) 획득 → 아바타 시즌팩 뽑기 → 쇼룸 전시** 루프. |
|  |  |

### II. 핵심 기능 구조

### 1️⃣ 해킹 러닝 모드 (이벤트 / 파티 협동 미션)

'해킹'은 특정 기간, 특정 GPS 위치에서만 참여 가능한 **협동형 레이드 이벤트**입니다.

| 단계 | 설명 |
| --- | --- |
| **🎯 개요** | 운영진이 실제 지역의 러닝 코스 또는 랜드마크를 기반으로 **'해킹 스팟(악성 기지)'**을 설정하고 기간 한정 이벤트로 오픈합니다. |
| **🧭 진행 방식 (파티/솔로)** | 유저가 스팟 근처(GPS 기반)에 진입 후 앱 내에서 **방 생성(최대 4인) 또는 QR 참가**를 통해 미션에 참여합니다. |
| **난이도 설정** | 방장(솔로 참여 시 본인)이 총 달성해야 하는 **공동 목표 거리/시간**을 난이도에 따라 설정합니다. (난이도에 따라 획득 가능한 데이터 칩 수량 차등) |
| **미션 목표** | 러닝 활동으로 발생한 에너지가 스팟의 HP(목표 거리)를 감소시킵니다. **파티원 모두의 기여가 실시간으로 합산**되어 공동 목표에 반영됩니다. |
| **달리기 화면** | 실시간 **'해킹 진행률(프로그레스 바)'** 및 파티원별 아이콘과 기여도를 명시하여 협동심을 자극합니다. |
| **종료 및 결과** | 목표 HP를 모두 감소시키거나, 설정된 시간이 종료되면 미션 종료. 해킹 성공 시 **데이터 칩**을 포함한 최고 등급 보상 지급. |

### 2️⃣ 파티 플레이 시스템

물리적인 근거리에서만 활성화되는 강력한 소셜 부스팅 기능입니다.

| 요소 | 상세 설명 |
| --- | --- |
| **QR 코드 파티** | '해킹 러닝' 모드 진입 후 방 생성 시 QR 코드를 생성하며, **근거리에 있는 유저만 스캔하여 파티에 즉시 참여 가능**합니다. (스크린샷 공유 불가, 물리적 동반 러닝 유도) |
| **파티 보너스** | 파티 구성 시 **경험치 및 크레딧 1.5배** 보너스 적용. 해킹 미션 성공 시 **데이터 칩 추가 분배.** |
| **협동 메커니즘** | 해킹 목표(HP) 감소 기여도 합산. 공동 목표 달성 시 **함께 성취하는 경험** 제공. |

### 3️⃣ 성장 및 경제 시스템 (보상 루프)

획득한 두 가지 재화(데이터 칩, 크레딧)를 통해 아바타를 꾸미고 성장시킵니다.

| 구분 | 재화 (획득처) | 사용처 | 희귀도 및 목적 |
| --- | --- | --- | --- |
| **데이터 칩** | **해킹 러닝 성공** (최고 보상), 주간 퀘스트 최고 보상 | **시즌팩 뽑기** (랜덤 박스) | **핵심 희귀 재화.** 시즌 한정/희귀 아바타 아이템 획득. 수집 및 과시 욕구 충족. |
| **크레딧** | 기본 달리기 퀘스트, 해킹 러닝 기본 보상 | **일반 상점** (확정 구매) | **기본 일반 재화.** 일반 의류, 액세서리 등 베이직 아이템 확정 구매. |
| **경험치** | 모든 러닝 활동 및 퀘스트 완료 시 | **러닝시티 레벨** 상승 | 프로필 레벨 상승. 친구 목록 및 쇼룸 전시. |

### 4️⃣ 일일/주간 퀘스트 및 스트릭

일상적인 러닝 루틴을 형성하고 크레딧을 보상하는 기본 게이미피케이션 요소입니다.

| 요소 | 설명 |
| --- | --- |
| **일일 퀘스트** | 하루 1~2개 목표 제공 (예: 3km 러닝 완주, Zone3 유지 10분). 달성 시 **자동 완료**되며, 유저가 '완료' 버튼 클릭 시 크레딧 지급. |
| **주간 퀘스트** | 온보딩 시 설정한 목표 달성 횟수(예: 주 3회 러닝) 기준. 주간 목표 달성 시 **데이터 칩** 또는 대량의 크레딧 지급. |
| **스트릭** | 일일 퀘스트 연속 달성 일자를 캘린더로 시각화하여 꾸준함을 독려. |

### III. 보상 우선순위 및 지급 구조

사용자의 노력과 미션의 중요도에 따른 명확한 보상 체계를 구축합니다.

| 순위 | 콘텐츠 | 보상 강도 및 종류 | 주요 역할 |
| --- | --- | --- | --- |
| **🥇** | **해킹 러닝 성공 (파티/솔로)** | **최고 보상:** **데이터 칩** (확정 또는 수량 랜덤), 대량의 경험치, 특별 배지. | 시즌팩 뽑기 재화 확보, 최고 성취감 제공. |
| **🥈** | **주간 목표 달성** (스트릭) | **중간 보상:** 데이터 칩 소량 또는 크레딧 대량. | 꾸준함 유지 동기 부여. |
| **🥉** | **일일 퀘스트 달성** | **기본 보상:** 크레딧 소량, 경험치. | 매일 앱 접속 및 러닝 루틴 형성 유도. |

### IV. 해킹 플레이 시나리오 요약

해킹 이벤트가 사용자에게 어떻게 인식되고 완료되는지에 대한 흐름입니다.

| 단계 | 흐름 | 설명 (사용자 관점) |
| --- | --- | --- |
| **1. 인지** | 던전 일정 사전 공지 및 지도 표시 | 앱 알림 또는 지도 탭에서 기간 한정 해킹 스팟 위치와 목표 난이도를 확인합니다. |
| **2. 진입** | 코스 근처 진입 → 던전 자동 인식 | 러닝 코스/스팟 근처(GPS)에 도착하면 '해킹 시작 가능' 버튼이 활성화됩니다. |
| **3. 설정** | 난이도 및 파티 설정 | 방을 만들거나(난이도 선택), QR 코드로 친구와 파티를 구성하고 미션을 시작합니다. |
| **4. 실행** | 러닝 시작 → 실시간 HP 감소 | 러닝 활동을 시작하면 달린 거리가 실시간으로 해킹 스팟의 HP를 깎는 애니메이션과 함께 표시됩니다. |
| **5. 종료** | 목표 달성 및 보상 지급 | 해킹 목표 거리(HP)를 공동으로 달성하면 러닝이 종료되고, **데이터 칩 획득 화면**으로 전환됩니다. |
| **6. 활용** | 아바타 성장/과시 | 획득한 데이터 칩으로 부티크에서 시즌팩을 뽑고, 획득한 레어 아이템을 쇼룸에 전시합니다. |

### V. 핵심 차별점 요약

| 요소 | 러닝시티의 설명 |
| --- | --- |
| **해킹 = 현실 코스** | GPS 기반 실제 러닝 코스/스팟에서 진행되는 **기간 한정 협동 이벤트.** 운동에 명확한 목적성과 공간적 몰입감 부여. |
| **데이터 칩 보상 루프** | 러닝을 통한 **희귀 재화(데이터 칩)** 획득 → **아바타 커스터마이징(시즌 뽑기)** →**쇼룸 전시/과시**로 이어지는 강력한 동기 부여 사이클. |
| **삼성 디바이스 연동** | 삼성 워치/폰 연동을 통해 심박수 등 **초정밀 생체 데이터**를 러닝 에너지로 사용하여, '갓생 인증'에 필요한 정확한 기록 확보. |
| **느슨한 소셜 연대** | 오프라인 크루의 부담 없이, **QR 파티 런**을 통해 현장에서만 친구와 즉시 협력하여 보상(데이터 칩)을 배가시키는 유연한 협동 시스템. |
